How do I get a Client ID?
  1. Open Google Cloud Console and create a project.
  2. Enable the Google Drive API.
  3. Set up the OAuth consent screen (External) and add yourself as a test user.
  4. Create credentials → OAuth client ID → Web application.
  5. Under Authorized JavaScript origins add the address you serve this page from, e.g. http://localhost:8000 or your GitHub Pages URL. It will not work from file://.
  6. Paste the Client ID above. It is stored only in this browser. Your data lives in jarvis-data.json on your Drive.
